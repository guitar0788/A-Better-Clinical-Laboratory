# V8 mechanical design study (FA checkpoint A / 2026-11-02)

This study is a **new, independently authored source experiment** and is **not** the replacement for the V7 GameDB assets. All game XML, original art mappings and the previously working clinical G1 implementation remain untouched. The prior V7 aesthetic verdict is **FAIL**.

`tools/art001_v8_study.py` creates eight editable SVGs and independent 128 × 128 RGBA preview frames for the mass spectrometer and sample-digestion workstation, with an original phone sheet. All four views are generated by 90° physical rotations of the same 3D-consistent authored geometry, rather than reflecting a finished sprite. Each instrument has a coherent cabinet and real front/rear component distinction, additional shaded shell panels, vents, sample modules, control and display components. The previews deliberately omit fake floor shadows.

**This remains a design study, not an accepted solution.** The generator supplies simple isometric polygonal geometry and may still fail owner expectations of the game's polished art. Exporting it into the existing production atlas would be premature. The next decision is a visual comparison with native HEM/RIA at native 1× scale, using owner's local proprietary references only (never redistribute). If the machine bodies still read as flat geometry, replace them with genuinely hand-authored layered illustration rather than tweaking automated edges again.
