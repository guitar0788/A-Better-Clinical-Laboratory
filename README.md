# A Better Clinical Laboratory

A Project Hospital mod expanding the existing clinical laboratory with additional laboratory rooms, medical tests, and equipment.

## Project status

**Pre-alpha — not released.** The earlier G0 disposable-save probe was reported to complete a CBC test inside a fourth laboratory room. That result does **not** validate the new G1 blood-lead examination, the patient-spawn panel, game-DLL compilation, or compatibility testing.

The initial Alpha 0.1 scope is one toxicology laboratory, two original interactive devices, three sampling/testing pairs, three clinical cases, and English/Chinese localization. The **two-month target begins only after the Alpha kickoff is recorded**; it is a planning target, not a promised release date.
